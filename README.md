#  About

This repository documents my journey of mastering Core Java by implementing concepts through small, focused programs rather than relying only on theory.

The repository is organized into topic-wise modules, with each package demonstrating a specific Java concept using practical examples. The objective is to develop a strong understanding of Java fundamentals, write clean and maintainable code, and build a solid foundation for backend development, Spring Boot, and technical interviews.

As I continue learning, this repository will expand to include advanced Java topics such as Collections Framework, Streams API, Generics, JVM Internals, Design Patterns, Networking, and File Handling.
